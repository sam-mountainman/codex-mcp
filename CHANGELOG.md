# Changelog

## 0.1.0 - 2026-07-12

- Initial public release.
- Added the Claude Code plugin and bundled stdio MCP server.
- Added `gpt_plan`, `gpt_ask`, `gpt_review`, `gpt_continue`, and `gpt_status`.

- Forced read-only Codex execution with non-interactive approvals.
- Added ChatGPT/API-key setup, local marketplace installation, unit/MCP/live smoke tests, and bilingual documentation.
